# Документы

- **`HYPERFRAMES-PLAYBOOK.md`** — справочник по приёмам HyperFrames: контракт
  композиции, 48 атомарных правил движения, 22 блюпринта, каталог из 447 блоков,
  планка качества и грабли, проверенные на своих прогонах.
- **`MLX-VIDEO-NOTES.md`** — заметки по локальному конвейеру на Apple Silicon:
  LTX-2.3 на MLX, ролевые теги Calliope, шим Claude, клонирование голоса.

Оба написаны по ходу работы: это не пересказ документации, а то, чего в ней нет.
