# claude-calliope

Обвязка к [Calliope](https://github.com/benjiyaya/Calliope) для Apple Silicon:
раскадровку пишет Claude по подписке, видео рендерят локальные MLX-графы ComfyUI.

Calliope сама по себе — хорошая локальная студия: проекты, биты, сцены, клипы,
очередь заданий и вызов ComfyUI по HTTP. Плагин закрывает то, обо что спотыкаешься
на Mac в первый же час.

## Что внутри

| | |
|---|---|
| `scripts/shim.py` | OpenAI-совместимый сервер поверх `claude -p`. Позволяет подставить Claude вместо локальной LLM **без API-ключа** — на подписке Claude Code |
| `scripts/tag_workflow.py` | Конвертер ComfyUI-графа из UI-формата в API-формат и разметка ролевыми тегами, которые читает Calliope |
| `scripts/calliope_ctl.py` | Статус сервисов, импорт графов, прогон шота, ожидание задания |
| `scripts/start.sh` / `stop.sh` | Запуск всей связки (в апстриме только `.bat`) |
| `patches/` | Четыре диффа к Calliope — без двух из них назначение роли `story` не работает вовсе |
| `examples/` | Размеченный граф LTX-2.3 MLX: переход между первым и последним кадром |

## Установка

```bash
claude plugin marketplace add llirikkcoder/claude-calliope
claude plugin install claude-calliope
```

Дальше — `/calliope` без аргументов покажет, что поднято и что подключено.

Плагину нужны: установленная Calliope, запущенный ComfyUI и `claude` CLI в `PATH`.

## Зачем Claude вместо локальной модели

На раскадровку 40-секундного ролика:

| | время | результат |
|---|---|---|
| qwen3:14b через Ollama | 624 с | 60 битов, по-английски, шаблонно |
| Claude через шим | 19 с | 4 бита, на языке идеи, операторскими планами |

Разница в числе битов — не про модель: в апстриме парсер длительности не понимал
русских единиц и читал «12 сек» как 12 минут. Это чинит `agent_prompts.patch`.

## Две вещи, на которых теряют время

**Ролевой тег нельзя вешать на произвольную кастомную ноду.** Патчер Calliope пишет
одно значение на ноду, а имя поля выводит из `class_type` по эвристике. Для
неизвестного класса он промахивается мимо настоящего виджета — и значение теряется
**молча**: задание отработает со старым промптом, ошибки не будет. Точкой входа
должна быть `Primitive*`-нода, подключённая ссылкой к нужному входу.

**Роль `story` в апстриме настраивается, но ни на что не влияет.** Поле есть в
конфиге и в интерфейсе, однако `generate_structured()` создаёт клиента без роли и
всегда идёт на активный профиль. Три патча из `patches/` пробрасывают роль до вызова.

Подробности и остальные грабли — в `skills/claude-calliope/SKILL.md`.
